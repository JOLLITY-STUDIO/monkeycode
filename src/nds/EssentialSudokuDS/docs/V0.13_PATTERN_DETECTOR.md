# V0.13 Pattern Detector (ADR-013)

## 背景
V0.12 curated 命名靠手工 disasm 阅读, 进展慢 (28 entries in V0.12.0+V0.12.1, 86 in V0.12.2 with 2 batches).
V0.13 用 regex 模式自动匹配 disasm, 把常见 pattern 函数自动命名 (`auto_<kind>_<addr8>`).

## 设计
**脚本**: `scripts/pattern_detector.py` (single-file, no deps)
**输入**:
- `rom-data/function-table.json` (V0.8 2700 entries)
- `rom-data/disasm-arm9-full.txt` (237875 lines)
- `rom-data/disasm-arm7-full.txt` (62573 lines)

**输出**:
- `rom-data/v013-pattern-suggestions.json` (51 suggestions)

**模式 (14 种)**:
| kind | pattern | confidence | 说明 |
| ---- | ------- | ---------- | ---- |
| state_setter | `ldr r1,[pc,N]; str r0,[r1]; bx lr` | high | global state setter |
| state_getter | `ldr r0,[pc,N]; ldr r0,[r0]; bx lr` | high | global state getter |
| byte_getter | `ldr r0,[pc,N]; ldrb r0,[r0]; bx lr` | high | byte getter |
| byte_setter | `ldr r1,[pc,N]; strb r0,[r1]; bx lr` | high | byte setter |
| halfword_getter | `ldr r0,[pc,N]; ldrh r0,[r0]; bx lr` | high | halfword getter |
| halfword_setter | `ldr r1,[pc,N]; strh r0,[r1]; bx lr` | high | halfword setter |
| const_return | `mov r0,#N; bx lr` | high | constant return |
| struct_clear_0 | `mov r1,#0; str r1,[r0]; bx lr` | high | single field clear |

## 5-Tier 优先级 (V0.13)

```
Tier 1: V0.4 known       (is_known=true, 28 fixed)
Tier 2: V0.12 curated    (manual disasm reading, 86 entries)
Tier 3: V0.13 pattern    (regex auto-match, 51 entries)  ← NEW
Tier 4: V0.10 heuristic  (sfloat_/util_/helper_, 23 entries)
Tier 5: sub_<addr>       (catch-all placeholder)
```

**V0.13 总命名**: 28 + 86 + 51 + 16 + 0 + 7 = **188 / 2669 = 7.04%** (V0.12.2: 137, +51)

## 已知限制

1. **Thumb 模式函数未覆盖**: disasm-arm9-full.txt 只解 ARM mode. 307 个 odd-address 函数 (实际 Thumb) 没有 disasm, 跳过. V0.13.1+ 可以加 thumb disasm.

2. **同一模式多 global dedup**: 多个 `global_dword_get` 没 dedup (e.g. `_d`, `_e`, `_f`...). V0.13 保留 addr 后缀避免 collision, 但仍然冗余. V0.14+ 可以做 global ptr 聚类.

3. **ARM-mode-only**: ARM7 部分函数在 thumb 模式未覆盖. 同 #1.

4. **Pattern 不能识别业务语义**: `auto_state_setter_02020f3c` 仍不知道它 set 哪个 global. V0.14+ 可以 cross-reference ldr pc-relative target 来推断 global 名字.

## V0.13+ 候选
