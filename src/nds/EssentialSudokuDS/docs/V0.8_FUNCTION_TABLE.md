## 算法 (8-tier 分类)

每个 unique BL/BLX callee 按以下 priority 分类:

1. **`real`** (high) — callee address 精确等于某个 `push {..lr..}` site
2. **`near`** (high) — callee 在 push site ±0x40 范围内 (手写 manual frame)
3. **`bx_lr`** (medium) — callee 在 [0..+0x800] 内有 `bx lr` (单指令裸函数 / 长函数)
4. **`pop_pc`** (medium) — callee 在 [0..+0x400] 内有 `pop {..pc..}` (compiler epilogue)
5. **`mov_pc`** (medium) — callee 在 [0..+0x400] 内有 `mov pc, lr` (explicit return)
6. **`ldm_pc`** (medium) — callee 在 [0..+0x400] 内有 `ldm xx!, {..pc..}` (function end)
7. **`b_target`** (medium) — callee 是 `b imm` 跳转目标 (编译期 jump table)
8. **`naked`** → 二级 fallback:
   - 多 caller (≥2) → `multi_caller` (medium) — 强信号, 肯定是函数
   - 单 caller + 非 skipdata → `single_caller_real` (low) — init/trampoline
   - 单 caller + skipdata → `data_target` (excluded) — V0.3 capstone 误识别

## ADR-008: 函数边界自动检测 = push + bx_lr + pop_pc + mov_pc_lr + multi-caller + skipdata filter

**Decision**: 用 8-tier 启发式 + skipdata 排除 检测 ARM9/ARM7 函数。

**Consequences**:
- ✅ Lib 函数命名覆盖率 0.5% → 98.58% (~200x)
- ✅ 给后续 TS service 代码翻译提供: addr → name + confidence 的稳定 mapping
- ✅ 区分 `data_target` (V0.3 capstone 误识别) 防止垃圾命名污染
- ❌ single_caller_real (low confidence 201 个) 不能自动翻译, 需人工或 unicorn 解析
- ❌ `bx rX` (3598 个 V0.4 BUG-004) 仍未处理 → 需要 unicorn emulation

**Verification**:
- ✅ V0.4 已知 12 个 named functions 全部映射到新 table (`vec2_set_inline`, `ipc_fifo_recv_handler`, `__aeabi_*`, etc.)
- ✅ ARM7 100% detected (audio IRQ handlers, IPC 等)
- ✅ `0x02391398` (naked 之前) 现在归类为 `bx_lr` (medium)

## V0.4-001 BUG 闭环

V0.4 BUG-001 描述:
> ARM9 全量 2181 unique callees, V0.4 仅 best-effort 给 12 个命名
> 待办: V0.5 用 IDA Free 自动扫函数边界 → 命名覆盖率提升到 ≥80%

**Resolution (V0.8.1)**:
- 用 capstone + 启发式 (不依赖 IDA Free) 实现同等覆盖
- 覆盖率 0.5% → 98.58% (远超 80% 目标)
- 输出 `function-table.json` 直接可被 TS 翻译层引用

V0.5 plan 中提到的 IDA Free / Ghidra 已被 capstone 启发式替代:
- IDA Free 需安装商业软件 + GUI, 不在 sandbox 可用
- Ghidra 需要 ≥1GB Python 环境, sandbox 不允许重 init

未来如果需要更高精度, 再评估 unicorn2 emulation 解析 bx rX (V0.4 BUG-004).

## 用法示例

```python
import json
ft = json.load(open('rom-data/function-table.json'))

# 1. 给定 addr 查询名称
addr = '0x02039f4c'
fn = next((f for f in ft['functions'] if f['addr'] == addr), None)
if fn:
    print(f"Address {addr}: {fn['name']} (confidence={fn['confidence']})")

# 2. 统计已知 vs 未知
known = [f for f in ft['functions'] if f['is_known']]
unknown = [f for f in ft['functions'] if not f['is_known']]
print(f"Known: {len(known)}, Unknown: {len(unknown)}")

# 3. 按 caller count 排序找热点
import operator
top_called = sorted(ft['functions'], key=lambda f: -(f.get('callers_n') or 0))[:20]
for f in top_called:
    print(f"  {f['addr']}: {f['name']} ({f.get('callers_n', '?')} callers, conf={f['confidence']})")
```
