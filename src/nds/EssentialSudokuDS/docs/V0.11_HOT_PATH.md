# V0.11 — ARM9 Hot-Path BFS (ADR-011)

> V0.11 catalog ARM9 entry BFS reachability, 给 V0.12 (curated naming) 提供 ground-truth tree.

## V0.10 痛点 (背景)

V0.10 (ADR-010) 给 callers ≥ 10 的 funcs 加 `util_/helper_` 前缀, 但:

1. **前缀仅 callers 数量启发式** — `util_0202f0c4` 不一定真 utility, 也可能是 game-loop dispatch
2. **命名覆盖率仍 3.6%** — 2689 个 `sub_XXX` 仍无业务记忆点
3. **业务代码看不懂** — 看到 `ARM9.helper_020283f0` 不知道是不是 render submit / input poll / scene dispatch

V0.11 不直接命名 (那太 ambitious), **只 catalog**:
- Reachability tree (forward BFS from entry)
- Tier classifier (entry_root → frame_loop → subsystem → worker → leaf_helper)
- First-disasm snippet for each tier-1+ func (前 8 行 disasm)
- Reverse-link catalog (top 30 hot funcs + their entry-zone callers)

让人类 (V0.12) 能 reads these + disasm snippets, 然后 hand-curate 真业务名.

## Algorithm (ADR-011)

### Forward BFS
1. **Start**: `0x02008000` (ARM9 entry, BIOS 跳转地址)
2. **Entry zone**: 0x02000000..0x02020000 (= 32KB window around entry, ~32 KB ARM9 binary 起始区)
3. **BFS rule**: 从 entry zone 内任何 BL-instruction caller_addr 出发的 callee 全部归为 depth=1 (frame_loop tier)
4. **Max depth**: 5 hops (浅 BFS 找出 hot path 主要 tier)
5. **Filter**: 跳过 SOFTFLOAT region (0x0204C000..0x0204DFFF) — 用 `sfloat_*` tier 单独列出

### Tier Classifier

| Tier          | BFS depth | 含义                              |
| ------------- | --------- | --------------------------------- |
| `entry_root`  | 0         | ARM9 entry (main loop start)      |
| `frame_loop`  | 1         | 每 frame 调用 (entry zone callees) |
| `subsystem`   | 2         | 子系统核心                        |
| `worker`      | 3         | 子系统下属 worker                  |
| `leaf_helper` | 4+        | 内嵌 helper                        |
| `sfloat`      | (any)     | SOFTFLOAT region (ADR-005)        |

### First-disasm Extractor
对每个 non-sfloat 到达 addr, 从 `disasm-arm9-full.txt` 抽 first 8 real insn 跳过 `;` skipdata placeholders.

### Reverse-link Catalog
对 top 30 hot funcs (`callers_n >= 10`), 输出:
- `total_entry_zone_callers` — 多少 BL-instruction callers 落在 entry zone
- `total_other_callers` — 多少 callers 在 zone 之外
- sample 5 entry_zone callers + 5 non-entry-zone callers (for reverse path back to entry)

这帮助 V0.12 推断:
- `total_entry_zone_callers == total_callers` → fn 是 entry 内 exclusive use (e.g. always-on update)
- `total_entry_zone_callers == 0` → fn 是 deep subsystem only (e.g. on-demand render)

## 已知 Limitations (V0.11.0 BUG)

- **V0.11.0-001**: `entry_root` tier 的 BL-source 聚合算法仅基于 function-calls.json JSON 静态分析, 没做 entry mid-body 虚拟 partition. 实际 BL-source `0x02008004` 是 loop 内第一个 BL, `0x02008734` 是 loop 中段, `0x0200a000` 是 loop iteration end — **这些应区分**. V0.11.1 改进 entry partition (读 disasm 找 B 跳转 / loop pattern)
- **V0.11.0-002**: BFS 浅 5 hops, 深 nesting helper (BFS-depth > 5) 不在 hot-path-tree 内. V0.11.1 加 `--max-depth 8` 选项.
- **V0.11.0-003**: first_disasm 仅 ARM-mode (disasm-arm9-full.txt). Thumb-mode funcs 没解析. V0.11.1 解析 disasm-arm9-full thumb 段.
