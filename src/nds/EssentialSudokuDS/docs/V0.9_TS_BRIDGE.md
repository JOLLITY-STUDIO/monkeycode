## 函数 naming 规则

每条 `sub_XXXXXXXX` 名字 = 16 进制 RAM 地址 (`0x` 前缀去掉).

如果 V0.4 KNOWN_NAMES dict 有命名 → 用 V0.4 名称:
```
0x02028434 → vec2_set_inline    (V0.4 named)
0x02039f4c → vec3_dot_product   (V0.4 named)
0x02039f38 → vec3_normalize     (V0.4 named)
0x02029bb0 → state_switch_8way_packed (V0.4 named)
0x023913b8 → ipc_fifo_recv_handler (V0.4 named)
```

V0.4 没命名的 → 自动 `sub_XXXXXXXX`:
```
0x0203a880 → sub_0203a880       (auto)
0x02106954 → sub_02106954       (auto)
```

TS 不支持的字符 (e.g. 关键字) 会自动 prefix `_fn_`:
```
class → _fn_class
if → _fn_if
```

## 每个 const 的 JSDoc

```typescript
/**
 * ARM9 函数 @ 0x02039f4c
 * @category bx_lr
 * @confidence high
 * @callers 154
 */
export const vec3_dot_product = 0x02039f4c as const;
```

JSDoc 在 TypeScript IntelliSense hover 时会显示. 鼠标悬停 vec3_dot_product:
- **所属**: ARM9
- **地址**: 0x02039f4c (RAM)
- **类别**: bx_lr (V0.8.1 8-tier 中第 3 tier)
- **confidence**: high (有 push 或 bx lr 邻接)
- **被调用**: 154 次 (top callee)

`function-records.json` 提供完整 2700 records array, 允许 runtime 查表:

```typescript
// miniprogram/utils/nds/function-records.json
import records from './utils/nds/function-records.json';

// 查找指定 addr 的函数
const fn = records.find(r => r.addr === 0x02039f4c);
if (fn?.confidence === 'high') {
  console.log(`High confidence function: ${fn.name}`);
}
```

## ADR-009: TypeScript bridge 一次性生成, 不用手写 const

**Decision**: 用 Python 脚本一次性生成 V0.8 函数表到 TS const 文件, 不手写.

**Consequences**:
- ✅ RE 改动 (V0.8 BUG 闭环) → 重跑脚本即可同步 TS 端命名
- ✅ TS 业务代码 (SudokuBoard 等) 可以直接 `import { ARM9.sub_02039f4c } as vec3_dot_product`
- ✅ 类型系统自动 identity check (防止子模块 import 错的 ADR-001 编号)
- ❌ 2700 个 const 累计 ~3 MB TS 文件, IDE IntelliSense 略慢 (实测仍 < 100ms)
- ❌ "V0.4 known names" 仅 28 个, 大量 sub_0203a880 类自动命名无记忆点 (用 callers_n / category 在 grep 找)

**Verification**:
- ✅ `npx tsc --noEmit` 0 errors (在 V0.9 生成的 7 个 TS 文件中)
- ✅ 预存 template 文件 (`miniprogram/pages/index/index.ts`) 有 2 pre-existing TS1005 errors, 跟 V0.9 无关
- ✅ Smoke test (`utils/nds/smoke.ts`) 在 Node REPL 跑过

### 2. 模糊查找 (caller count)

```typescript
import records from './utils/nds/function-records.json';

// 找出调用次数 >= 50 的高频函数 (= game logic hot path)
const hot = records
  .filter(r => (r.callers_n ?? 0) >= 50)
  .sort((a, b) => (b.callers_n ?? 0) - (a.callers_n ?? 0));

console.log(`Top ${hot.length} hot functions:`);
hot.slice(0, 10).forEach(r => {
  console.log(`  ${r.addr.toString(16)}: ${r.name} (${r.callers_n} callers, conf=${r.confidence})`);
});
```

### 3. 类型 conversion helper

```typescript
import { ARM9 } from './utils/nds';
import { Addr } from './utils/nds';

export type Arm9AddrLiteral = typeof ARM9 extends infer T
  ? T[keyof T]
  : never;

export function isARM9(addr: number): addr is Arm9AddrLiteral {
  return Object.values(ARM9).includes(addr);
}

// 调用
if (isARM9(0x02039f4c)) {
  // ... 类型安全
}
```
