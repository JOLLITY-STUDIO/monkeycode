# V0.10 — Helper 命名启发式 (ADR-010)

> V0.10 升级 V0.9 的 TypeScript bridge: 给 hot-callers / SOFTFLOAT-region funcs 加语义前缀, 提高 IDE IntelliSense 可读性.

## V0.9 痛点 (背景)

V0.9 codegen 输出 2700 entries, 但 2672 个 (98.96%) 是 `sub_XXXXXXXX` 自动命名, **无业务语义**:

```typescript
import { ARM9 } from './utils/nds';
ARM9.sub_02039f4c    // 这是 vec3_dot_product V0.4 known, 实际上!
ARM9.sub_020216c0    // callers=25, hot path, 但名称看不出做什么
```

TypeScript IDE 只显示地址, 业务代码 `import { sub_0202f0c4 }` 完全认不出哪个 function 是 game loop hot path / render / dispatch.

## V0.10 方案: 4-Tier Heuristic Naming

按 **priority (高到低)**, 给 funcs 加 prefix:

| Priority | Prefix         | 触发条件                                            | 期望数量 (实测) | 含义                          |
| -------- | -------------- | --------------------------------------------------- | --------------- | ----------------------------- |
| 1        | (V0.4 known)   | `is_known=true`                                     | 28              | 已有命名最优先, 永不改         |
| 2        | `sfloat_`      | 0x0204C000 ≤ addr < 0x0204E000 (SOFTFLOAT region)   | 18              | ADR-005 `__aeabi_*` 软浮点 lib |
| 3        | `util_`        | callers ≥ 20 + 非 SOFTFLOAT region                  | 12              | High-utility lib              |
| 4        | `helper_`      | callers ≥ 10 + 非 SOFTFLOAT region                  | 40              | Medium helper                 |
| -        | `sub_`         | 其他 (callers < 10)                                 | 2571            | Init / 0 caller / 内嵌, 无业务语义 |

**覆盖率提升**: V0.9 = 28/2700 ≈ 1.04% → V0.10 = 98/2700 ≈ **3.6%** (3.5x improvement).

实际统计 (V0.10 generator run):
```
sfloat    : 18  (SOFTFLOAT region unknown funcs)
util      : 12  (callers ≥ 20)
helper    : 40  (callers ≥ 10)
none      : 2571 (callers < 10 OR 0 caller — sub_XXXXXXXX)
known     : 28  (V0.4 ADR-005 partial naming — unchanged)
excluded  : 31  (data_target — not renamed)
```

## Naming 规则详解

### Tier 1: V0.4 known (28 fixed)
- `is_known=true` 由 `LIBRARY_MAP.md` 手工命名 (28 个 V0.4 confirmed)
- 永远保留 V0.4 名称, 不被 heuristic 覆盖
- 例: `vec3_dot_product`, `__aeabi_fadd`, `touch_sample_xy`

### Tier 2: `sfloat_<addr>` (18 funcs)
- ADR-005: ARM9 region 0x0204C000..0x0204DFFF 是 devkitPro `__aeabi_*` 软浮点 lib
- 28 V0.4 known `__aeabi_*` 已 in region 但保留 V0.4 names (priority 1 wins)
- 18 其他 funcs in same region (unknown) 被 naming 为 `sfloat_<addr>`
- TS 端用 JS `Number` 直接覆盖 (IEEE 754 double = 软浮点)

### Tier 3: `util_<addr>` (12 funcs)
- callers ≥ 20 (callers 数从 V0.3 call graph 推导)
- 非 SOFTFLOAT region
- 命名暗示 "high-utility lib", 但 **前缀只是提示**, 不保证是真 utility
- 真实语义需要 V0.11+ ARM9 BFS hot path 分析才能确定

### Tier 4: `helper_<addr>` (40 funcs)
- callers ≥ 10 (callers 略低)
- 非 SOFTFLOAT region
- 命名暗示 "medium helper"

### Tier 5: `sub_<addr>` (保持不变, 2571 funcs)
- callers < 10, OR
- confidence = 'excluded' (data_target), OR
- 单纯 init / 一次性 / 内嵌 funcs

## 用法示例 (V0.10)

```typescript
import { ARM9, Known } from './utils/nds';

// V0.4 known (priority 1, 不变)
Known.vec3_dot_product     // 0x02039f4c
Known.__aeabi_fadd          // 0x0204db1c
Known.touch_sample_xy       // 0x02384350

// V0.10 helpers (新)
ARM9.util_0202f0c4          // callers=49, hot helper
ARM9.util_0200a098          // callers=48
ARM9.util_020216c0          // callers=25
ARM9.helper_020216c0_2      // (冲突) — collision suffix
ARM9.helper_0204399c        // callers=20
ARM9.sfloat_0204d7e8        // SOFTFLOAT region (callers=23)
ARM9.sfloat_0204c074        // SOFTFLOAT region (callers=19)
ARM9.sub_02010000           // 0 caller, init code, 保持
```

## Type System Changes (V0.10)

`FunctionRecord` 接口加 2 个字段 (V0.10):

```typescript
export interface FunctionRecord {
  // ... V0.9 fields unchanged
  
  /** V0.10: 是否 heuristic 推测命名 (true: sfloat_/util_/helper_) */
  readonly is_heuristic: boolean;
  /** V0.10: heuristic 命名 category (仅 is_heuristic=true) */
  readonly heuristic_kind?: 'sfloat' | 'util' | 'helper';
}
```

`function-records.json` runtime iteration 同样扩展 — 多了 `is_heuristic` + `heuristic_kind` 字段.

JSDoc 在每个 helper const 加 `@heuristic <kind> (V0.10 ADR-010)` 标记, IDE IntelliSense hover 可见.

## ADR / 决策

完整 ADR-010: `.codebuddy/DECISIONS.md` ADR-010 段.

**核心决策**: `4-tier heuristic naming — region + callers 静态分析`.

**Rejected alternatives**:
- (a) **手写 100+ 名** — 不可扩展 (V0.8 改 heuristic 后要重写)
- (c) **runtime JSON lookup** — IDE type 帮助差
- (d) **IDA / Ghidra 推送命名** — sandbox 不可用 (跟 ADR-008 同样约束)
- (e) **regexp 推测函数名前缀** — ARM 没 symbol table, 不可行

## BUG (V0.10)

详见 `BUG.md` V0.10.0-001..003.

- V0.10.0-001 — `util_/helper_/sfloat_` 前缀仅基于启发式, 不真业务语义 (med priority)
- V0.10.0-002 — SOFTFLOAT region 仅 ARM9 (cos minor — ARM7 stub-only per ADR-007)
- V0.10.0-003 — `sfloat_*` 不会重命名已 known `__aeabi_*` (cos — ADR-010 priority 设计正确)
