; ============================================
; 反汇编模式确认报告（04 Disassembler 输出）
; 基于 arm9.bin + 数据格式 + 截图交叉验证
; ============================================
; 关键函数地址（主调度器跳转表已确认）
;   0x0205113C  MAIN_SCHEDULER（双层分派：SUBSTATE→STATE）
;   0x02053BF4  MODE_INIT_A（状态初始化，r0=1 时由 0x02051468 bl 调用）
;   0x0205418C  MODE_INIT_B（资源预加载，由 0x02051470 bl 调用）
;   0x02055BC8  GAME_SETUP（游玩场景装配，0x02051510 bl 调用）
;   0x020518A4  模式校验/退出处理（检查 r0, #0x28 等状态）
;
; 调度器分支中模式参数区分：
;   0x02051460: cmp r0, #1 → bne 0x2051828 → bl 0x2053bf4 (MODE_INIT_A)
;   0x02051480: bl 0x2053be4（状态读取）→ cmp r0, #6 → addls pc...（跳转表）
;   0x020515D4: bl 0x2053bf4 → 对应模式 r0=0（map）进入
;   0x020517F0: bl 0x2055bc8 → GAME_SETUP 装配，随后 bl 0x2051adc（状态切换）
;   0x02051804: cmp r0, #2 → bne（可能是模式 2 = fap 的完成检查）
; ============================================

; ---- 资源路径硬编码（arm9.bin 数据段，_find_resource_refs.py 确认）----
; map_d/  : 404 处硬编码字符串（arm9 偏移 0x81804，RAM 0x02081804）
; lap_d/  : 407 处硬编码字符串（arm9 偏移 0x86F38，RAM 0x02086F38）
; fap_d/  : 405 处硬编码字符串（arm9 偏移 0x8B80C，RAM 0x0208B80C）
; 说明：三种模式分别加载独立数据目录，无交叉混用。

; ---- 数据格式差异（06 资源提取 + 截图交叉验证）----
; map（map_d/）: 6 字节头 + nibble 主体（低半字节在前）
;   值域 0..15 → 直接映射 16 色调色板
;   对应截图: drawing-001-Carp.png（上屏目标图 + 下屏涂色网格）
;   结论: map = 涂色/绘图模式（Paint / Color by Numbers）
;
; lap（lap_d/）: 26 字节头 + 每格 1 字节
;   值低 4 位 = 格子内容，bit3~bit6 = 方向连接编码（路径走向）
;   对应截图: maze-007.png（上屏目标图 + 下屏连线迷宫网格）
;   结论: lap = 连线/迷宫模式（Line Art / Maze）
;
; fap（fap_d/）: 2 字节头 + nibble 主体（低半字节在前）+ 尾部 bitmap
;   值 1..9 = 提示数字，15 = 填充色，0 = 空
;   对应截图: 31205-magipic.png（上屏目标图 + 下屏数字提示网格）
;   结论: fap = 数格子/像素填充（Magipic / Fill-A-Pic）

; ---- 反汇编调用链验证 ----
; 主循环 0x02000BA4 → bl 0x2051040 → 进入调度器
; 调度器 0x0205113C → SUBSTATE=1 → bl 0x2053be4 → r0=1 → bl 0x2053bf4 (MODE_INIT)
; MODE_INIT 0x02053BF4:
;   设置 r2=0x65 (101), r0=3, strh r2,[r1,#6] → 模式参数写入全局结构
;   调用 0x20062EC（可能为数据加载入口）→ 后续根据模式 ID 分支到不同资源路径
; GAME_SETUP 0x02055BC8:
;   被 0x02051510 bl 调用，用于装配游玩场景（grid / palette / UI）
;   三种模式在此处分路：map 使用 nibble 调色板渲染，lap 使用方向路径渲染，fap 使用数字提示渲染
;   完成检查 0x02055D9C → result==2 → 进入 achieve 0x020514 (ST_ACHIEVE)

; ============================================
; 最终确认：
;   map  ≠  maze（截图 maze-007 实际对应 lap 模式）
;   lap  =  maze / line-art（连线模式）
;   map  =  paint / drawing（涂色模式）
;   fap  =  magipic / fill-a-pic（数格子模式）
; ============================================
