## 背景

bank13-15 是纯音频数据 bank（BGM 乐谱字节），没有代码。之前已提取到 `src/game/data/prg/audio/bgm/`：
- 43 个 SID 轨道文件 BGM_0x30.ts ~ BGM_0x5B.ts
- 每个含 SQ1/SQ2/TRI/NOISE 4 轨道 + RAW 原始字节 + NES_BASE 基址 + META 元数据
- Index.ts 汇总导出

ASM 侧现在已拆分成 `data_tables.s` / `data_maps.s` / `data_tail.s`（纯 .byte）。

## 任务

对照 ASM 的 data 拆分和现有 TS 数据，逐字节核对校准：

1. 读 `asm/bank13/_full.s`、`asm/bank14/_full.s`、`asm/bank15/_full.s` 确认每个 bank 的原始字节
2. 读 `src/game/data/prg/audio/bgm/Index.ts` 了解 BGM 映射
3. 读几个 BGM_0xXX.ts 样本确认数据格式
4. 对照：BGM_0xXX.ts 的 RAW 字节是否和 ASM bank13/14/15 对应地址的 .byte 一致
5. 修正偏移/补充缺失轨道
6. 给 ASM 侧的 data_tables.s/data_maps.s/data_tail.s 加注释标明对应的 BGM 编号
7. 验证：`npx tsc -p tsconfig.json --noEmit` + `cd asm && python build_nes.py && python verify_bytes.py`

## 校准规则

- BGM 编号 0x30-0x5B 对应 bank12-15 的不同地址段
- 每个 BGM 有 header（轨道指针）+ 4 轨道数据
- NES_BASE 是该 BGM 在 PRG 中的 CPU 基址（如 $8000+$偏移）
- RAW 是完整原始字节，用于和 ASM .byte 对照
