```
$00:9950 → bank-00.ts:ppuClearArea()
  │ 循環: STA $2007 = 0x00 (清 VARM)
  │ DEY / BNE $9950
  │
  ├─ $00:9956: LDA $E6 → 計算下一個 VRAM 行
  │  ADC #$20, STA $E6
  │  LDA $E7, ADC #$00, STA $E7
  │  DEC $E8, BNE $9942 → 繼續下一行
  │
  └─ $00:9967: 恢復 PPU 狀態
     STA $2001 (PPU_MASK = $1E)
     STA $2000 (PPU_CTRL = $88, 開 NMI)
     RTS → 返回調用者 $85A2

$00:85A2 → bank-00.ts:ppuClearInit()
  │ LDA #$00, STA $E6
  │ LDA #$24, STA $E7  (VRAM 起始 $2400)
  │ LDY #$20, LDX #$20
  │ JSR $98E8 → ppuClearArea()
  │
  └─ 切換到 bank-01 $A8D5:

$01:A8D5 → bank-01.ts:oamDmaSetup()
  │ 循環: 讀 $0468+Y → OAM buffer $0200+Y
  │ 寫入 4 bytes per sprite: Y, tile, attr, X
  │ INY x4; 若 Y != 0 繼續 → 直到填滿 256 OAM bytes
```

### 渲染流程

```
1. NMI 觸發 (每幀開始)
   │
   ├─ bank-30 (固定 Bank $0F): NMI 向量
   │   JSR 到 bank-02 NMI handler
   │
   └─ bank-02.ts: bank02_nmiHandler()
       │
       ├─ 檢查 $0628 (PPU 數據就緒)
       ├─ 關 PPU 顯示 ($2001 = 0)
       ├─ 處理 PPU 數據隊列 ($05E8-$0627)
       │   → 寫 palette/nametable 到 VRAM
       ├─ 重置 PPU addr latch → $3F00
       └─ 恢復 PPU_MASK + PPU 狀態

2. VBLANK 後 → 主循環 (bank-00)
   │
   ├─ bank-00.ts: 場景狀態機
   │   ├─ 標題畫面狀態 → 讀 bank-01 數據表
   │   ├─ 開場動畫狀態 → 控制精靈序列
   │   └─ 比賽準備狀態 → 載入球員陣容
   │
   ├─ bank-12.ts (bank $06): 每幀執行
   │   ├─ MML 音頻解析 → 控制 APU 通道
   │   └─ 精靈 slot 管理 → 位置/屬性更新
   │
   └─ bank-01.ts: PPU 寫入輔助
       └─ 寫 tile/palette 數據到 PPU

3. PPU 硬體渲染 (每幀結束後)
   │
   ├─ VRAM (nametable) → 背景渲染
   ├─ OAM ($0200-$02FF) → 精靈渲染
   └─ Palette RAM → 顏色查找表
```
