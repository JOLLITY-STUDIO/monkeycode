# 第10章: PK合戦 (PK Shootout)

> 说明书原文: 5人ずつ交互にシュート → 決着 → サドンデス

## 对应的 Bank 代码

| Bank | 文件 | 作用 |
|:---:|------|------|
| **26** | `bank-26-match-engine-code.ts` | **比赛引擎** — PK模式 ($802A) |

## Bank 26 PK 模式入口

```
$802A → PK shootout / special mode
  → 检测: リオカップ决赛/淘汰赛平局 → 进入 PK
  → 选择 5 名踢球者
  → 交互射门
```

## PK 操作流程

### 第一步: キッカー選択 (选5人)

| 操作 | 代码 |
|------|------|
| 十字键选球员 | Bank 26 `$8024` → player select |
| R确定 = 加入 PK 序列 | Bank 26 `$8027` |
| 5人选完 → R → 开始 | Bank 26 → PK start state |

### 第二步: 交互シュート

| 操作 | 代码 |
|------|------|
| 射门方选コース | 左スミ / 正面 / 右スミ |
| 守方选 GK 方向 | 左 / 中 / 右 (预判) |
| 比数 | Bank 26 进球数跟踪 |

### サドンデス (突然死亡)

| 条件 | 代码 |
|------|------|
| 5人平分 → 继续 | Bank 26 → sudden death flag |
| 一方进一方不进 → 结束 | Bank 26 → PK result → back to Bank 00 |

## 数据依赖
- 球员属性: Bank 27/28 (射门力/技术影响 PK 成功率)
- 陣型数据: 无需 (PK 是独立模式)
- GK 能力: Bank 27 → GK 属性 (扑救成功率取决于守门值)

## 实现要点
```
PK 模式状态机:
  1. 选择踢球者状态
  2. 射门方向选择状态 (攻击方)
  3. 扑救方向选择状态 (守备方)
  4. 结果判定状态 (进球/扑出)
  5. 比分检查状态 → 5轮完? 平分? → suddendeath?
  6. 结束 → 场景切换
```
