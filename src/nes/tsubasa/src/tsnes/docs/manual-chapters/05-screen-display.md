| Bank | 文件 | 作用 |
|:---:|------|------|

## Bank 02 — NMI 渲染器 ($8000-$9FFF)

每帧 VBlank 期间由 Bank 30 调用 `JSR $8000`:

```
$8000-$8065: NMI handler 主入口
  → 保存寄存器
  → 递增帧计数器
  → 执行场景 tick (bank30 → bank16)
$8073-$8106: PPU scroll/属性/MMC3/手柄更新
  → 设置 scroll 寄存器
  → 更新 MMC3 IRQ
  → 读取手柄输入到 $0042/$0043
$8107-$8137: 手柄输入 + 帧 tick
$8160-$81E3: 精灵 DMA 传输 (OAM $0200-$02FF → PPU)
$820C-$821A: bank02 跳转表
```

## Bank 11 — 背景/瓦片渲染器

```
JMP vectors at $8000:
  $8000 → bank11_init       (初始化/渲染)
  $8003 → bank11_scrollUpdate (scroll 更新)
  $8006 → bank11_tileWrite  (tile 写入设置)
  $8009 → bank11_attrSetup  (属性表设置)
```
- 基于元 tile 的 nametable 更新引擎
- 每帧处理增量 tile 变化（只写变化的部分）

## Bank 22 — 精灵/OAM 引擎

完全脱离 ROM 字节解析，使用 **LayoutItem[] JSON**:
- 管理场上 22 名球员的精灵动画
- 消费 Bank 08/18/21 的精灵数据
- 处理碰撞检测/动画帧切换
