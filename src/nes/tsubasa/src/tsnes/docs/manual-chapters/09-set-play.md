# 第9章: セットプレイ (Set Play / 定位球)

> 说明书原文: コーナーキック/ゴールキック/スローイン/フリーキック/ペナルティキック

## 对应的 Bank 代码

| Bank | 文件 | 作用 |
|:---:|------|------|
| **26** | `bank-26-match-engine-code.ts` | **比赛引擎** — 所有定位球逻辑 |

## Bank 26 定位球分发

```
$8015 → event manager
  → 检测球出界位置 → 决定定位球类型
  → 犯规位置 → PK (禁区内) / FK (禁区外)
  → 进入对应 Set Play 模式
```

## (1) ペナルティキック (PK)

| 操作 | 代码 |
|------|------|
| キッカー選択 | Bank 26 `$8024` command → 十字键选球员 |
| シュートコース選択 | Bank 26 → 十字键选方向 (左/中/右) |
| 门将被挡出 → 继续 | Bank 26 `$8012` goal detect → rebound |

**攻撃方界面**: 左スミ / 正面 / 右スミ

**守備方界面**:
- 十字键选 GK 扑救方向 (左/中/右)
- 成功扑出 → 继续比赛

## (2) 選手のポジション変更 (CK/FK 专用)

| 操作 | 代码 |
|------|------|
| "かえる" → ◎选中 | Bank 26 → Bank 20 menu |
| "チェンジ" → 选球员 | Bank 26 → 十字键移动光标 |
| 选目标位置 → 移动 | Bank 26 → 更新阵型站位 |
| "おわる" → 确定 | Bank 26 → 结束编辑 |

## (3) コーナーキック (CK)

| 操作 | 代码 |
|------|------|
| キッカー選択 | Bank 26 `$8024` → 球员选择 |
| 球员位置调整 | Bank 26 → Bank 20 换位界面 |
| パス or シュート选择 | Bank 26 command menu |

## (4) フリーキック (FK)

| 位置 | 操作 | 代码 |
|------|------|------|
| 远离球门 | 只传不射 | Bank 26 → 限制为パスのみ |
| 球门前 | 可选直接射门 | Bank 26 → パス/シュート选择 |
| 射门威力 +2 级 | Bank 26 → 射门参数 boost |

**攻撃方界面**: パス / シュート → 射门 → 选方向 (左/中/右)

**守備方界面**:
- 球员位置调整
- 力ベ (人墙) 位置选择 → 左/中/右
- 成功 → 防住射门

## (5) スローイン (界外球)

| 操作 | 代码 |
|------|------|
| 十字键移动光标 | Bank 26 → 选传球目标 |
| R确定 | Bank 26 `$8027` → 界外球执行 |

## (6) ゴールキック (门球)

同样的传球选择界面。

## 整体流程
```
球出界/犯规
  → Bank 26 event manager 判定类型
  → 进入 Set Play UI 状态
  → 球员位置编辑（CK/FK）
  → 执行传球/射门
  → 返回比赛状态
```
