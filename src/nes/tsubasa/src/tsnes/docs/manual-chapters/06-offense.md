## Bank 26 — 比赛引擎分派表

```
JMP vectors at $8000-$803B:
  $8006 → match init          (比赛初始化)
  $8009 → player collision    (球员碰撞/抢球)
  $800C → player state machine (球员状态机)

  $8015 → event manager       (事件管理)
```

## 进攻命令 & 代码实现

### (1) ドリブル (带球)

| 操作 | 代码 |
|------|------|

### (2) パス (传球)

| 操作 | 代码 |
|------|------|

### (3) シュート (射门)

| 操作 | 代码 |
|------|------|

### (4) ワン・ツー・リターン (二过一)

### (5) 浮き球処理 (高球)
