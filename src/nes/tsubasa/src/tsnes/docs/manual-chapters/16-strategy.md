## 策略 & 代码实现

### (1) 両サイドからセンタリング (边路传中)

兵法: 从两边传中到禁区内 → 敌方碰撞概率低

```
Bank 26 → 传球路线计算
  → 检查路线上的敌方球员位置
  → 传到禁区空间 (区域传球)
  → 计算敌方拦截概率 (基于 Bank 27 球员"拦截"值)
  → 接球 → 射门
```

**Bank 30 坐标计算**: 球位置 → 目标位置 → 中间球员检测

### (2) スルー (让球通过)

兵法: GK 出击时最有效

```
Bank 26 → GK 出击判定
  → スルー命令执行
  → 球路线显示 (preview)
  → 最近球员跑去接空门
  → GK 被骗 → 空门曝光
  → 射门成功概率大幅度提升
```

**Bank 26 状态机**:
```
浮き球攻撃 → スルー选择
  → Bank 19 lookup: 球 trajectory
  → Bank 22 sprite: 球动画帧
  → 最近友方 AI 去取球
```

### (3) キーパーこぼれ球 (GK 扑救脱手)

兵法: GK 出击脱手 → 空门 → 立即射门

```
Bank 26 → GK 出击判定 (パンチ)
  → 球弹出 (rebound physics)
  → 一定时间空门状态 (ゴールガラ空き)
  → 快速抢球 → シュート
```

### (4) 地域パス (区域传球/直塞)

兵法: 传向空地让队友跑位接球

```
Bank 26 → 传球光标位置选择
  → 不选球员选空地
  → 最近队友 → AI 跑位去接
  → 敌方路线检测 → 避免拦截
  → 到达 → 接球成功
```

### (5) 鋭角シュート (小角度射门)

兵法: 小角度射门容易被立柱弹回或被防守覆盖 → 尽量避免

```
Bank 26 → 射门角度计算
  → 计算球到球门的角度
  → 小角度 → 降低射门成功率
  → ポスト命中率增加
  → Bank 19 → 射门威力衰减
```

### (6) キーパー抜き (过 GK)

兵法: 不用射门，直接过人 → 空门

```
Bank 26 → ドリブル vs GK 1v1
  → 球员过GK技能判定 (Bank 27 属性)
  → 成功 → 自动射门 (空门)
  → ガッツ消耗小 (40 vs 80+)
```

```
比赛环:
  Bank 26 $801B match flow
    → $800C: 球员状态机 (逐帧更新)
    → 每个球员:
      - 球权状态 → 进攻或防守

    → $8015: 比赛时间管理
```
