## 代码实现

```
命令执行流程:
  Bank 26 $8024 → 玩家选择命令
    → 查 Bank 19 查找表: 命令ID → ガッツ消耗值
    → 当前球员ガッツ >= 需要值?
      YES → 减少体力 → 执行命令 → 结果判定
      NO  → 命令失败 → 显示体力不足
    → 如果不执行命令 (不动) → ガッツ自然回复

ガッツ回复:
  Bank 26 $8015 event manager → 每帧回复值
    = 基础回复值 × Bank 29 球员回复系数
```
