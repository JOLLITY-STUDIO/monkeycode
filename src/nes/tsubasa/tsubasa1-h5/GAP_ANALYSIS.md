## 2. ROM 实际数据结构

### Bank 3 ($C000-$FFFF) - 数据 Bank
```
跳转表入口:
  $8000: JMP $C018   → 主入口
  $8003: JMP $C12D   → 子函数
  $8006: JMP $C38F   → 
  $8009: JMP $C403   →
  $800C: JMP $FEC0   → Bank 7 调用
  $8012: JMP $C191   →
  $8015: JMP $8092   → 内部函数

数据表:
  $C17D: 跳转表指针 (用于球员数据处理)
  $C31D: 属性值表 (15项，精灵属性?)
  $C4ED: 更大数据区域
```

### Bank 7 ($C000-$FFFF) - 固定 Bank
```
$C000:     22个脚本入口指针表
$C02C:     33个角色头像 CHR tile 引用
$C2C2:     RLE 解码器 (Bank 1 实际使用)
$E306-$F968: 74段文本数据 (tile编码)
```
