# Bank 0 完整语义注释 — 核心引擎

> ROM偏移: $00010-$03FFF | CPU地址: $8000-$BFFF | 9585行 | MMC1 Bank 0 (Switchable)
> 功能: RESET启动、NMI处理、主循环、状态调度、I/O、PPU更新、比赛核心逻辑

---

## 1. 跳转向量表 ($8000-$801B) — Bank 0 对外API

这是 Bank 0 供其他 Bank 调用的公共接口。每个入口是3字节的 `JMP addr`，共约28个API函数。

## 2. RESET 启动流程 ($809B-$80DF)

```
CPU上电 → 跳转向量 $FFC0 → MMC1初始化 → JMP ($8000) → 跳转到此处 $809B
```

### $809B-$80A0: 等待VBlank (第一次)

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $000AB | $809B | `SEI` | 关中断 (确保初始化期间不被NMI打断) |
| $000AC | $809C | `CLD` | 清十进制模式 (6502在复位后D标志未定义) |
| $000AD | $809D | `LDA $2002` | 读PPU状态寄存器 |
| $000B0 | $80A0 | `BPL $809D` | bit7=0 → 未到VBlank，继续循环等待 |

### $80A2-$80A6: 等待VBlank (第二次)

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $000B2 | $80A2 | `LDA $2002` | 再次等待VBlank确保PPU完全稳定 |
| $000B5 | $80A5 | `BPL $80A2` | — |

### $80A7-$80C2: 清零RAM ($0000-$07FF)

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $000B7 | $80A7 | `LDX #$FF` | X = 堆栈指针初始值 $FF |
| $000B9 | $80A9 | `TXS` | 设置堆栈指针 S = $FF |
| $000BA | $80AA | `LDA #$06` | PPU MASK = 仅显示背景(无精灵) |
| $000BC | $80AC | `STA $2001` | 写入PPU MASK寄存器 |
| $000BF | $80AF | `LDA #$00` | A = 0 |
| $000C1 | $80B1 | `STA ram_0000` | 指针低字节 = 0 |
| $000C3 | $80B3 | `STA ram_0001` | 指针高字节 = 0 |
| $000C5 | $80B5 | `TAY` | Y = 0 |
| $000C6 | $80B6 | `STA (ram_0000),Y` | **[循环起点]** 写0到 ($0000)+Y |
| $000C8 | $80B8 | `INY` | Y++ |
| $000C9 | $80B9 | `BNE $80B6` | Y != 0 → 继续 (覆盖$0000-$00FF，256字节) |
| $000CB | $80BB | `INC ram_0001` | 指针高字节++ |
| $000CD | $80BD | `LDX ram_0001` | X = 当前页 |
| $000CF | $80BF | `CPX #$08` | 已到第8页? ($0800) |
| $000D1 | $80C1 | `BNE $80B6` | 未到 → 继续清零下一页 |

> **清零范围**: $0000-$07FF (CPU RAM 2KB全部清零)

### $80C3-$80DD: 核心变量初始化

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $000D3 | $80C3 | `LDA #$00` | — |
| $000D5 | $80C5 | `STA ram_0016` | **Scroll X = 0** |
| $000D7 | $80C7 | `STA ram_0017` | **Scroll Y = 0** |
| $000D9 | $80C9 | `LDA #$10` | 背景pattern表=$1000, NMI开启, 名称表=$2000 |
| $000DB | $80CB | `STA ram_0019` | **PPU_CTRL 镜像 = $10** |
| $000DD | $80CD | `LDA #$06` | 仅显示背景 |
| $000DF | $80CF | `STA ram_0018` | **PPU_MASK 镜像 = $06** |
| $000E1 | $80D1 | `JSR $82CC` | → 初始化PPU更新缓冲区 (设置默认VRAM写入地址) |
| $000E4 | $80D4 | `JSR $8371` | → 清除OAM精灵数据 |
| $000E7 | $80D7 | `JSR $838F` | → 清空所有nametable和属性表 |
| $000EA | $80DA | `JSR $82F5` | → 开启NMI中断 |
| $000ED | $80DD | `JMP $81EE` | → **跳转到主循环** |

## 3. NMI 中断处理器 ($80E0-$812E)

```
每个VBlank时由PPU触发，CPU跳转到 $8002 → JMP $80E0
执行顺序: 保存寄存器 → OAM DMA → PPU队列 → 手柄输入 → 
          随机数更新 → (Bank切换+游戏逻辑调用) → 帧计数++ → 恢复寄存器 → RTI
```

### $80E0-$80EC: 保存CPU状态

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $000F0 | $80E0 | `PHA` | 保存 A |
| $000F1 | $80E1 | `JSR $82EB` | 关闭NMI (清除 $2000 bit7) |
| $000F4 | $80E4 | `LDA ram_0018` | 读取PPU MASK镜像 |
| $000F6 | $80E6 | `STA $2001` | 写入PPU MASK (确保vblank期间渲染关闭) |
| $000F9 | $80E9 | `TXA` | — |
| $000FA | $80EA | `PHA` | 保存 X |
| $000FB | $80EB | `TYA` | — |
| $000FC | $80EC | `PHA` | 保存 Y |

### $80ED-$80F6: OAM DMA

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $000FD | $80ED | `LDA #$00` | OAM地址 = 0 |
| $000FF | $80EF | `STA $2003` | 写OAMADDR |
| $00102 | $80F2 | `LDA #$02` | DMA源地址 = $0200 |
| $00104 | $80F4 | `STA $4014` | **触发OAM DMA**: 256字节从$0200→OAM |

### $80F7-$80FF: 核心NMI处理

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $00107 | $80F7 | `JSR $812F` | → **处理PPU更新队列** (写入VRAM) |
| $0010A | $80FA | `JSR $81B9` | → **读取手柄输入** |
| $0010D | $80FD | `JSR $82AD` | → **更新随机数发生器** |

### $8100-$811A: Bank切换与游戏逻辑

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $00110 | $8100 | `LDA ram_0093` | Bank切换锁 |
| $00112 | $8102 | `BNE $811B` | 如果已锁定 → 跳过Bank切换 |
| $00114 | $8104 | `LDA ram_001A` | CHR Bank 0选择 |
| $00116 | $8106 | `JSR $83CF` | → 写入MMC1 CHR Bank 0寄存器 |
| $00119 | $8109 | `LDA ram_001B` | CHR Bank 1选择 |
| $0011B | $810B | `JSR $83D7` | → 写入MMC1 CHR Bank 1寄存器 |
| $0011E | $810E | `LDA #$01` | MMC1控制寄存器值 |
| $00120 | $8110 | `JSR $83C7` | → 写入MMC1控制寄存器 |
| $00123 | $8113 | `JSR $DB00` | → **[Bank切换后调用]** 当前Bank的 $DB00 逻辑 |
| $00126 | $8116 | `LDA ram_001C` | PRG Bank选择 |
| $00128 | $8118 | `JSR $83C7` | → 恢复PRG Bank (写入MMC1) |

### $811B-$812E: NMI收尾

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $0012B | $811B | `LDA #$00` | — |
| $0012D | $811D | `STA ram_05FA` | 音效队列索引清零 |
| $00130 | $8120 | `INC ram_0300` | **帧计数+1** (主循环等待此值非零) |
| $00133 | $8123 | `PLA` | 恢复 Y |
| $00134 | $8124 | `TAY` | — |
| $00135 | $8125 | `PLA` | 恢复 X |
| $00136 | $8126 | `TAX` | — |
| $00137 | $8127 | `JSR $82F5` | 重新开启NMI |
| $0013A | $812A | `LDA $2002` | 读PPU状态(清除VBlank标志) |
| $0013D | $812D | `PLA` | 恢复 A |
| $0013E | $812E | `RTI` | **中断返回** |

## 4. PPU 更新队列系统 ($812F-$81B8)

### $812F-$8153: 主PPU队列处理 (双缓冲)

```
队列结构: ram_0305=队列条目数, ram_0306-ram_0338=队列数据
每帧从队列中取一个条目处理: 2字节指针(数据地址) + 后续数据
```

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $0013F | $812F | `LDX ram_0305` | 队列条目数 |
| $00142 | $8132 | `BEQ $8154` | 队列为空 → 处理静态缓冲区 |
| $00144 | $8134 | `LDX ram_0305` | **[循环]** 重读条目数 |
| $00147 | $8137 | `DEX` | 条目数-1 |
| $00148 | $8138 | `BMI $8150` | 所有条目处理完 → 调scroll |
| $0014A | $813A | `STX ram_0305` | 更新剩余条目数 |
| $0014D | $813D | `TXA` | — |
| $0014E | $813E | `ASL` | ×2 (每个条目2字节指针) |
| $0014F | $813F | `TAX` | — |
| $00150 | $8140 | `LDA ram_0306,X` | 读取条目指针低字节 |
| $00153 | $8143 | `STA ram_0012` | → ram_0012 (ppuPtr L) |
| $00155 | $8145 | `LDA ram_0307,X` | 读取条目指针高字节 |
| $00158 | $8148 | `STA ram_0013` | → ram_0013 (ppuPtr H) |
| $0015A | $814A | `JSR $818D` | → 处理该条目的VRAM写入 |
| $0015D | $814D | `JMP $8134` | 继续处理下一个条目 |

### $8150-$8153: 队列清空后设置Scroll

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $00160 | $8150 | `JSR $833A` | → 设置PPU滚动寄存器和CTRL |
| $00163 | $8153 | `RTS` | — |

## 5. 手柄输入读取 ($81B9-$81ED)

### $81B9-$81D9: 主入口

```
读取两个手柄状态:
  保存上一次状态 → $0303(joy1_prev), $0304(joy2_prev)
  读取当前状态 → $0301(joy1_cur), $0302(joy2_cur)
```

| 偏移 | 地址 | 指令 | 注释 |
|------|------|------|------|
| $001C9 | $81B9 | `LDA ram_0301` | 当前Joy1状态 |
| $001CC | $81BC | `PHA` | 暂存 |
| $001CD | $81BD | `LDA ram_0302` | 当前Joy2状态 |
| $001D0 | $81C0 | `PHA` | 暂存 |
| $001D1 | $81C1 | `LDX #$01` | — |
| $001D3 | $81C3 | `STX $4016` | 锁存手柄 (写1→strobe) |
| $001D6 | $81C6 | `DEX` | X=0 |
| $001D7 | $81C7 | `STX $4016` | 释放锁存 (写0→strobe) |
| $001DA | $81CA | `JSR $81DA` | → 读手柄1 (X=0) |
| $001DD | $81CD | `INX` | X=1 |
| $001DE | $81CE | `JSR $81DA` | → 读手柄2 (X=1) |
| $001E1 | $81D1 | `PLA` | — |
