## 1. 概述

Bank 04 包含游戏的最核心逻辑——**比赛引擎**。

| 功能 | 对应State/条件 | 说明 |
|------|---------------|------|
| **比赛初始化** | State 3 → State 4 | 设置队伍、球员、场地 |
| **比赛主循环** | State 4 | AI、玩家操作、物理、判罚 |
| **状态转换** | State 5 | 半场/进球/终场判断 |

## 3. State 流转

```
State 3 ($85CD): 比赛初始化
  ├→ 加载球队数据
  ├→ 设置阵型
  ├→ 初始化物理场地
  └→ transitionTo(4)

State 4 ($87B9): 比赛主循环
  ├→ AI 决策
  ├→ 玩家输入
  ├→ 物理计算
  ├→ 碰撞检测
  └→ 条件 → transitionTo(5)

State 5 ($820D): 状态转换管理器
  ├→ 半场 → back to State 4 or → State 6
  ├→ 进球 → State 6
  └→ 终场 → State 6
```
