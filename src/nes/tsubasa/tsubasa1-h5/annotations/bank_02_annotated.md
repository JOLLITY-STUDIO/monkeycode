## 1. 概述

Bank 02 包含多个辅助功能，核心角色是存储和提供数据指针表。

| 功能 | 说明 |
|------|------|
| **指针表** | 开场动画 RLE 数据指针、事件/剧情数据指针 |
| **NMI 辅助处理** | Bank 0 NMI 处理完成后可能调用的辅助功能 |
| **图形/调色板** | 标题画面等场景的调色板和 nametable 数据 |
| **Bank 7 数据读取** | Bank 2 代码可读取 Bank 7 `$C000-$FFFF` 的事件脚本 |

## 2. 关键数据表 (已确认)

### 2.1 开场动画指针表 — `$D05E` (8 条目)

```
$D05E: 开场动画页面指针表 (8 条目 × 2 字节)
  [0] $D068 → Page 0 RLE data (Bank 1 $D068)
  [1] $D07F → Page 1 RLE data (Bank 1 $D07F)
  [2] $D093 → Page 2 RLE data (Bank 1 $D093)
  [3] $D0A5 → Page 3 RLE data (Bank 1 $D0A5)
  [4] $D0B3 → (预留)
  [5] $D0BF → (预留)
  [6] $D0CB → (预留)
  [7] $D0DB → (预留)
```

⚠️ 注意: 前 4 个指针 `$D068-$D0A5` 虽在 Bank 2 定义，但指向 Bank 1 `$C000-$DFFF` switchable 区域的数据。

### 2.2 综合指针表 — `$D0F3` (32 条目)

```
$D0F3: 综合数据指针表 (32 条目 × 2 字节)
  其中:
  - 10 条指向 Bank 7 ($C000-$DFFF fixed 区)
  - 2 条指向 Bank 2 内部 ($8000-$BFFF)
  - 20 条用途待确认
```

### 2.3 标题画面调色板 — `$B24F`

```
$B24F: 标题画面调色板数据 (32 字节)
```

用于标题画面的调色板设置。

## 4. 与 Bank 7 的关系

Bank 2/3 代码可访问 Bank 7 固定区 ($C000-$FFFF):

```
Bank 7 $C000-$C02B: 22 条目内部指针表
Bank 7 $C064-$E28D: ~8KB 事件脚本数据
```

CDL 标记 `D 2` 和 `D 3` 表明 Bank 7 数据被 Bank 2/3 作为数据进行访问：
- `D 2` → Bank 2 读取该地址数据
- `D 3` → Bank 3 读取该地址数据

这意味着 Bank 2 包含读取/解析 Bank 7 事件脚本的函数。
