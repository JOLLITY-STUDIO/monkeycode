# Bank 06 — 菜单/事件/结果画面

> **源文件**: `_tmp_disasm_out/banks/bank_06_code.asm`
> **类型**: Code + Data Bank (Switchable)
> **CPU地址**: $8000-$BFFF | **ROM偏移**: $18010-$1BFFF | **大小**: ~693KB ASM
> **CDL标记**: 3,031 Code + 8,379 Data | **分析日期**: 2026-08-05

---

## 1. 概述

Bank 06 是游戏流程的「过场逻辑」中心，处理菜单选择、比赛事件（进球/半场）和结果画面。从 Bank 0 的 State Dispatcher 通过 `JSR $84D2` 被调度进入。

| State | Sub | 功能 | 调度指令 |
|-------|-----|------|---------|
| State 2 | Sub 0 | 菜单选择画面 | `LDA #$60, JSR $84D2` → Bank 6, Sub 0 |
| State 6 | Sub 3 | 进球/半场/终场事件 | `LDA #$63, JSR $84D2` → Bank 6, Sub 3 |
| State 7 | Sub 1 | 比赛结果画面 | `LDA #$61, JSR $84D2` → Bank 6, Sub 1 |

## 3. Sub 0 — 菜单选择 ($C00C+)

### 3.1 初始化入口 ($8026+)

```
$8026: LDA ram_071E       ; 是否已初始化?
$8029: BNE $8031           ; 已初始化 → 跳过
$802B: JSR $C40B           ; 初始化
$802E: INC ram_071E        ; 标记已初始化
```

### 3.2 主循环 ($8031-$8145)

```
$8031: LDA ram_064F        ; 比赛阶段
$8034: CMP #$09
$8036: BCC $803B
$8038: INC ram_06F7        ; 阶段≥9 → 置特殊标记

$803B: LDA ram_06DD        ; 是否已进行简单设置?
$803E: BNE $804B
$8040: STA ram_0673
$8043: LDX #$5F
$8045: JSR $807D           ; 循环设置
$8048: INC ram_06DD

$804B: JSR $CFB1
$804E: LDA #$00
$8050: STA ram_06B5
$8053: JSR $DB27           ; 主逻辑
$8056: JSR $D90E           ; 辅助
$8059: JSR $D908           ; 辅助
$805C: JSR $C110           ; 核心处理
```

### 3.3 排序循环 ($805F-$8085)

```
$805F: LDX #$00            ; 外循环
$8061: TXA
$8062: CLC
$8063: ADC #$06
$8065: TAY                 ; Y = X + 6
$8066: LDA ram_06FF,X      ; 读取 A
$8069: CMP ram_06FF,Y      ; 比较 B
$806C: BCC $807C           ; A < B → 跳过交换
$806E: PHA                 ; 交换 A ↔ B
$806F: LDA ram_06FF,Y
$8072: STA ram_06FF,X
$8075: PLA
$8076: STA ram_06FF,Y
$8079: LDA ram_06FF,X
$807C: TYA
$807D: CLC
$807E: ADC #$06
$8080: TAY                 ; Y += 6
$8081: CPY #$18
$8083: BNE $8069           ; 继续内循环
$8085: JSR $D930           ; 递增 X
$8088: CPX #$12
$808A: BNE $8061           ; 继续外循环
```

这是一个冒泡排序/排名循环，对 `ram_06FF` 区域的 4 组（每组 6 个条目）数据进行排序。

### 3.4 特殊计数 ($808C-$80B9)

```
$808C: LDA #$00
$808E: TAX
$808F: TAY
$8090: LDA ram_0705,X      ; 读取条目 bit6
$8093: AND #$40
$8095: BEQ $8098
$8097: INY                 ; bit6 置位 → 计数+1
$8098: JSR $D930           ; X 递增
$809B: CPX #$0C
$809D: BNE $8090           ; 循环 12 次

$809F: LDA ram_0705        ; 第一位 bit5?
$80A2: AND #$20
$80A4: BEQ $80A9
$80A6: INY                 ; +1
$80A7: INY                 ; +1
$80A8: INY                 ; +1 (bit5 → +3)
$80A9: STY ram_06F8        ; 保存计数
```

### 3.5 阶段判断 ($80AC-$8110)

根据 `ram_064F`（比赛阶段）分路处理:

| 阶段 | 跳转 | 处理 |
|------|------|------|
| `$064F = 08` | `$80F4` | 特殊路径: LDA #$16, LDY #$01 |
| `$064F < 08` | `$80B7` | `ADC #$02` → 查表 |
| `$064F = 0D` | `$80D8` | 终场分支: 总分计算 |
| `$064F ≥ 08 && ≥ 0D` | `$80C3` | `SBC #$08` → 查表 $CE5F → JSR $CB36 |
| `$064F = 08` | `$80F4` | LDA #$16 |

### 3.6 最终输出 ($80D8-$810D)

```
$80D8: LDA ram_06FF        ; 第一名
$80DB: CLC
$80DC: ADC ram_0705        ; 加上额外值
$80DF: STA ram_0000
$80E1: LDA #$46            ; 基准值 70
$80E3: SEC
$80E4: SBC ram_0000
$80E6: STA ram_0717        ; 剩余 = 70 - (第一名 + extra)
$80E9: AND #$0F
$80EB: CLC
$80EC: ADC #$09
```

最终结果存入:
- `ram_06DC`: 生成的显示值
- `ram_06DE`: Y 寄存器衍生值

## 4. Sub 1 — 比赛结果画面 ($CF97+)

由 State 7 触发 (`LDA #$61, JSR $84D2`)。

### 4.1 主入口 ($81AA-$81D9)

```
$81AA: JSR $8011           ; 内部跳转
$81AD: LDA #$0E
$81AF: JSR $DBB4           ; 功能 A (参数 $0E)
$81B2: LDA #$0F
$81B4: JSR $DBB4           ; 功能 A (参数 $0F)
```

### 4.2 循环处理 ($81B7-$81D4)

```
$81B7: LDX #$00
$81B9: LDA $CE4A,X         ; 从数据表取指针低字节
$81BC: STA ram_00DE
$81BE: LDA $CE4B,X         ; 指针高字节
$81C1: STA ram_00DF
$81C3: TXA
$81C4: PHA
$81C5: LDA $CE4C,X         ; 第三字段
$81C8: JSR $CD4F           ; 调用处理函数
$81CB: PLA
$81CC: TAX
$81CD: INX                  ; X += 3
$81CE: INX
$81CF: INX
$81D0: CPX #$0F
$81D2: BNE $81B9           ; 循环 5 次 (5 个条目 × 3 字节)
$81D4: JSR $8014           ; 结束内部跳转
$81D7: INC ram_00E1
$81D9: LDA #$01
$81DB: JMP $D9F5           ; 退出
```

数据结构 `$CE4A` 处为 5 个条目，每条目 3 字节: `[ptr_L][ptr_H][arg]`

## 10. 子程序调用图

```
State 2 进入 (Sub 0):
  $8000 → JMP $C00C → 跳转到实际入口
  或直接 $8026+ 路径（Bank 0 通过 $8017 间接跳转进来）
    ├→ JSR $C40B (初始化)
    ├→ JSR $CFB1 (数据处理)
    ├→ JSR $DB27 (主逻辑)
    ├→ JSR $D908, $D90E (辅助)
    ├→ JSR $C110 (核心处理)
    └→ 排序循环 + 特殊计数 → 结束

State 7 进入 (Sub 1):
  经由内部跳转表 ($8011)
    ├→ $81AA: JSR $DBB4($0E), JSR $DBB4($0F)
    ├→ $81B7: 循环 5 次处理 $CE4A 数据表
    └→ $81D4: JSR $8014, JMP $D9F5

State 6 进入 (Sub 3):
  经由内部跳转表
    ├→ $81DE: JSR $DC42($18), JSR $D60F($11)
    ├→ $81F8: JMP $C21C (主事件处理)
    └→ $81FB: 分镜计数循环 ($06B3)
         ├→ 每8帧: JSR $D615 (动画更新)
         └→ 结束: JSR $DBA9($02)
```
