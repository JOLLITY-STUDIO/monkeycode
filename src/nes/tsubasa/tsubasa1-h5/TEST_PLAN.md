# 测试计划 (Test Plan)

> 基于当前项目进度和架构分析，覆盖核心模块、状态机、渲染管线、音频引擎和平台兼容性。

## T1 - 核心模块单元测试

**目标**：验证各底层工具模块的正确性。

| 模块 | 测试要点 |
|------|---------|
| `DataCache` | Key-Value 读写、批量写入、缓存命中/未命中、内存上限 |
| `OamCache` | 精灵属性读写（x/y/tile/attr）、OAM 排序、溢出处理 |
| `PpuQueue` | PPU 写入队列、$2006/$2007 双写地址锁存、地址自增模式 |
| `BankManager` | MMC1 配置（PRG/CHR Bank 切换）、Bank 越界保护、bankLock 机制 |
| `InputManager` | 按键状态（按下/按住/释放）、多键同按、轮询同步 |
| `RngGenerator` | 随机数分布、种子重置、固定种子可复现 |
| `BitUtils` | 位操作（读/写/翻转）、高低位拆分、进位/溢出标志 |
| `TileStore` | CHR 像素解码（2bpp→RGBA）、Tile 索引寻址、Bank 偏移计算 |

**依赖脚本**：`tests/state-test.ts`、`scripts/state_test.py`

---

## T2 - 状态机流转测试

**目标**：验证 8 个核心状态（State0~State7）的完整流转链。

| 测试项 | 描述 |
|--------|------|
| 正向流转 | State0→1→2→3→4→5→6→4(半场)→6→7→2 完整链路 |
| 逆向流转 | State7→2、State5→3 等跳过/回退路径 |
| 边界条件 | 非法状态值（<0, >7）、`bankLock` 保护下禁止切换 |
| 状态驻留 | 各状态的 enter/update/exit 生命周期完整性 |

**依赖脚本**：`scripts/state_test.py`（已有 46 个用例）
